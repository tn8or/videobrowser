# RaceBox overlay package

This directory holds the RaceBox VBO parser, Cairo overlay renderer, session
fetcher, and standalone CLI tools.

**Documentation lives at the repo root:**

- [README.md](../README.md) — install, `videobrowser scan` usage, outputs
- [INSTRUCTIONS.md](../INSTRUCTIONS.md) — product criteria and decisions

For day-to-day use, prefer `videobrowser scan` from the repo root. Standalone
commands (alpha overlays, manual download, batch render) are documented in the
root README under *Standalone RaceBox tooling*.
