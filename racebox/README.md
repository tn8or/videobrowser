# RaceBox overlay package

This directory holds the RaceBox VBO parser, Cairo overlay renderer and
session fetcher used by `videobrowser scan`.

**Documentation lives at the repo root:**

- [README.md](../README.md) — install, `videobrowser scan` usage, outputs
- [INSTRUCTIONS.md](../INSTRUCTIONS.md) — product criteria and decisions

A manual session download is documented in the root README under
*Manual RaceBox download*.
